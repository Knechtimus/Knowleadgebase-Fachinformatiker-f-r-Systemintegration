
# Vorwärtskalkulation
```
Listeneinkaufspreis (netto)
- Lieferrabatt
= Zieleinkaufspreis
- Lieferskonto
= Bareinkaufspreis
+ Bezugskosten
= Einstandspreis (Bezugspreis)
```

# Kaufvertrag

## Merkmale: 
- Einmalige hohe Anschaffungskosten
- Eigentum geht auf den Käufer über
- Abschreibung über die Nutzungsdauer

## Vorteile:
- Langfristig meist Günstiger
- keine laufenden Vertragskosten
- Freie Nutzung und Anpassung

## Nachteile:
- Hoher Kapitalbedarf
- Technologierisiko (alter)
- Wartungskosten selber tragen


# Leasing:

## Merkmale:
- Monatliche Leasingraten
- Gerät bleibt Eigentum des Leasinggebers
- Feste Vertragslaufzeit

## Vorteile:
- Geringe Anfangsinvestionen
- Planbare Kosten
- Technik kann regelmäßig erneuert werden

## Nachteile:
- Insgesamt höhere Kosten als Kauf
- Vertragsbindung
- Meist keine Kündigung vor Laufzeitende


# Miete:

## Merkmale:
- Kurzfristige Nutzung
- Monatlich kündbar
- Service oft inklusive

## Vorteile:
- Sehr flexibel
- Keine langfristige Bindung
- Wartung meist enthalten

## Nachteile: 
- Teuer bei langer Nutzung
- kein Eigentum
- Eingeschränkte Individualisierung

# Kurzübersicht:

| **Kriterium**  | **Kauf**      | **Leasing**  | **Miete** |
| -------------- | ------------- | ------------ | --------- |
| Eigentum       | Käufer        | Leasinggeber | Vermieter |
| Kosten         | Einmalig hoch | Monatlich    | Monatlich |
| Laufzeit       | Unbegrenzt    | Fest         | Flexibel  |
| Flexibilität   | Gering        | Mittel       | Hoch      |
| Langzeitkosten | Gering        | Mittel–hoch  | Hoch      |
